# File Context Selector

**File Context Selector** — это фоновая утилита для Windows, предназначенная для быстрого поиска, фильтрации и открытия файлов из текущей активной папки Проводника (Explorer) по горячей клавише.

---

## 🚀 Основные возможности

* **Вызов по горячей клавише:** Сочетание `Ctrl + Alt + Space` мгновенно открывает окно поиска для текущей открытой папки в Проводнике.
* **Нечеткий поиск (Fuzzy Search):** Быстрый поиск файлов и поддиректорий по частям имени (поддерживает разделение ключевых слов пробелами, точками или запятыми).
* **Фильтрация по расширениям:** Удобные кнопки и дропдаун для быстрой группировки и фильтрации файлов по типам (`.png`, `.pdf`, `.txt` и т.д.).
* **Режим рекурсивного поиска:** Возможность переключения между поиском только в текущей папке и сканированием вложенных директорий (сочетание `Alt + R`).
* **Интеграция с треем:** Работает в фоновом режиме, поддерживает автозапуск вместе с Windows.
* **Удобное открытие:**
  * `Enter` / `Return` — открыть выбранные файлы в ассоциативных программах по умолчанию.
  * `Shift + Enter` — открыть папку с выделением выбранных файлов в Проводнике.
  * Экспорт выбранного списка в `.csv`.

---

## 🛠 Зависимости и требования

* **ОС:** Windows 10 / 11
* **Python:** 3.10+

### Необходимые библиотеки:
* `PySide6` — графический интерфейс (Qt)
* `pywin32` — взаимодействие с Windows API и Проводником
* `rapidfuzz` — нечеткий поиск и сравнение строк

```bash
pip install PySide6 pywin32 rapidfuzz
```
